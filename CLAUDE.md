</autonomous_escalation_protocol>

<ponytail_minimalism_ladder>

1. YAGNI: Does this component actually need to exist? If no, strip it entirely.
2. REUSE: Is this already handled or patterned elsewhere in the context?
3. STDLIB: Can the native standard library handle this without installs?
4. NATIVE: Is there a native binary or default platform configuration that does this out of the box?
5. DEPENDENCY: Can an existing, already active dependency handle this?
6. ONE-LINE: Can this expression be cleanly executed in a single line?
7. MINIMUM WORK: Write only the absolute essential structure that functions flawlessly. Never over-engineer.
</ponytail_minimalism_ladder>
