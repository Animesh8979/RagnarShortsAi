# v5 Video Fix Plan — Repair Broken Composition Stack

## Goal
Fix the v5 ExplainerVideo composition so it renders a clean, visually coherent 1080×1920 video with proper layer separation, readable text, visible character, and synced mouth animation driven by caption timing.

## Root Cause (Verified by Audit)
- Critical JSX syntax errors (`style=\n{` instead of `style={{`) prevent building.
- Duplicate layer blocks (headline, subtitle, CTA rendered twice) cause visual collisions.
- Stray orphaned braces (`)}`) break the JSX tree.
- Legacy v4 layers (old captions at bottom, old CTA) still present and conflict with new v5 layers.
- `AuroraBackground` and `LottieCharacter` have unterminated import strings.

## Files to Modify
1. `apps/studio/src/compositions/ExplainerVideo.tsx` — Full rewrite/repair of the return JSX tree.
2. `apps/studio/src/components/AuroraBackground.tsx` — Fix import string and `style` prop syntax.
3. `apps/studio/src/components/LottieCharacter.tsx` — Fix import string and `style` prop syntax.
4. `apps/studio/src/components/TextReveal.tsx` — Verify no syntax issues.

## Step-by-Step Plan

### Step 1: Syntax Repair (All 3 Components)
- Replace ALL occurrences of `style=\n{` with `style={{`.
- Replace ALL occurrences of `import React from "react';` with `import React from "react";`.
- Ensure every opening `{` has a matching `}`.

### Step 2: Deduplicate & Clean ExplainerVideo.tsx
- Remove the duplicate inline headline block (lines 271-302 in current file).
- Remove the duplicate inline CTA block (lines 304-329).
- Remove the duplicate inline subtitle block (lines 331-353).
- Remove the stray orphaned `)}` at line 354.
- Remove the legacy v4 caption layer (lines 377-391).
- Remove the legacy v4 CTA (lines 356-375).
- Keep only: `midGroundPanel`, `characterLayer`, `headlineLayer`, `subtitleLayer` variables + the `isEnding` CTA block.

### Step 3: Fix Visual Hierarchy
- `AuroraBackground`: Keep `zIndex: 0`, full screen, `opacity: 0.3` for subtle background only. Remove `height: "50%"` restriction.
- `midGroundPanel`: Solid semi-transparent panel at `zIndex: 1`, bottom 70%. Mood-colored but not dark-muddy.
- `characterLayer`: Centered, `800×800`, `bottom: "10%"`, `zIndex: 2`. Not larger than the canvas.
- `headlineLayer`: `top: "15%"`, `zIndex: 2`. Remove dark background card — rely on text shadow for contrast so aurora shows through.
- `subtitleLayer`: `top: "58%"`, `zIndex: 2`. Reduce background opacity to 0.5 so panel doesn't completely block midground.
- `isEnding` CTA: `top: "80%"`, `zIndex: 2`, only during last segment.

### Step 4: Mouth Sync Logic
- Keep `isTalking = captions.some(...)` — this is correct and drives the Lottie mouth animation.
- Ensure `LottieCharacter` receives `isTalking` prop correctly.

### Step 5: Build & Verify
- Run `npx remotion still src/index.tsx ExplainerVideo --frame=10` to test hook frame.
- If build fails, capture error and iterate.
- If build succeeds, render 3 QA frames (start/mid/end) and check brightness/contrast.
- Render full video with `npx remotion render src/index.tsx ExplainerVideo --output=...`.

## Verification
- Frame 10: Aurora visible behind text, headline readable, character visible on panel.
- Frame 300: Mid-content frame with bright panel, active captions, talking character.
- Frame 660: End frame with CTA visible, fade-out not started.

## Risk: Low
This is a repair, not a redesign. v5 concepts (Aurora, Lottie, Transitions) are correct; they just need clean code to render.
